Project Description

The Student Grade Calculator is a simple Java application that accepts marks for multiple subjects and calculates the student's total marks, percentage, and grade.

The program also validates the entered marks to ensure that each subject's marks are between 0 and 100.

Objectives

- Practice Java variables and arrays.
- Understand "for" and "while" loops.
- Use conditional statements to calculate grades.
- Create methods for calculations.
- Validate user input.

Features

- Accepts marks for multiple subjects.
- Stores marks using an array.
- Calculates total marks.
- Calculates percentage.
- Assigns a grade based on the percentage.
- Rejects invalid marks below 0 or above 100.

Technologies Used

- Java
- JDK (Java Development Kit)
- Scanner class for user input

How to Run the Program

1. Install the Java Development Kit (JDK).

2. Copy the Java source code into a file named "Task2.java".

3. Open a terminal in the folder containing the file.

4. Compile the program:
   
   javac Task2.java

5. Run the program:
   
   java Task2

You can also run the program using an online Java compiler such as "Programiz Online Java Compiler" (https://www.programiz.com/java-programming/online-compiler/).
